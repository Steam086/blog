Fedora是半年更新一次版本，其软件包几乎都是最新的
现在我用的Fedora42，gcc版本是最新的 gcc15
![](image/Pasted%20image%2020250626122500.png)
就导致了不能编译CUDA代码，CUDA对gcc14以上的版本会报warning

重新自己编译一个版本的gcc很麻烦：

1. 编译时间长
	我的16G内存i7-12代CPU编译gcc12.3版本用了近半小时。编译时 -j不能太大不然会爆内存
2. 编译之后要想绕过系统内置gcc需要配置环境变量
	需要在PATH中加入，配置LD_LIBRARY_PATH，等一系列，因为有很多系统应用依赖系统的gcc，所以不能取代它，不能配置全局的环境变量
3. 还需要安装一系列binutils
	上述步骤走完之后我天真地以为可以正常编译了，但是g++提示我找不到'as'，也就是汇编器，我要再去下载一个，不知道后面还会有什么坑。


## 总结：

逐渐理解了**devcontainer**的作用，当我们需要多个环境的时候，devcontainer可以随便折腾
